A gold trading robot you can watch live

GoldTriEngine is an algorithmic Expert Advisor for MetaTrader 5 that trades gold (XAUUSD). It runs live on YouTube 24 hours a day, Monday to Friday, with an AI voice host that explains every trade as it happens, wins and losses.

Watch live on YouTube

Transparency. I am the developer of GoldTriEngine. The live stream currently runs on a demo account. The voice host is AI-generated. Results: Myfxbook (demo).

What you see on the stream

  • The live XAUUSD chart with every entry and exit
  • Live stats: trades, win rate, net result and drawdown
  • Warnings before big news (NFP, CPI, FOMC) and how gold reacted afterwards
  • Trading education between trades

The GoldTriEngine stream bot

A small program on the developer's own computer runs the stream. With the channel owner's permission it uses the YouTube Data API to name each live stream, set its description and thumbnail, read the live chat, and upload short clips (Shorts) to the GoldTriEngine channel. A companion tool, GoldTriEngine Shorts, uploads the same clips to the developer's own TikTok account. These tools only act on the developer's own accounts. See the privacy policy.
