What Is an Expert Advisor (EA) and How Does It Run on MetaTrader 5?

An Expert Advisor (EA) is a program written in MQL5 that runs inside the MetaTrader 5 terminal, reads prices and places, changes and closes trades by rules. It needs the terminal to stay open and connected, follows its rules without emotion, and is only as good as those rules.

YeliasPublished 5 November 20262 min read

The short version

An Expert Advisor, usually called an EA or a trading robot, is a small program that runs inside the MetaTrader terminal. It watches the price on the chart it is attached to, applies a fixed set of rules, and sends orders to your broker: open a trade, move a stop, close a position.

MetaTrader 5 EAs are written in a language called MQL5. The EA does not run on the broker's computer or on a website. It runs on your computer or on a rented server (a VPS) where your terminal is running, which has consequences for uptime that we cover in the VPS lesson.

What an EA actually does

  1. Reads data: the price, indicators and the state of your account.
  2. Checks its rules: for example, 'is there a setup, and is risk within limits?'
  3. Acts: places an order with a size and a stop, or manages an open trade.
  4. Repeats: every tick or every bar, for as long as the terminal is running and automated trading is switched on.

Things to check before you run any EA

  • What market and account type is it built for? An EA made for one instrument, time frame or account currency can misbehave on another.
  • How does it limit risk? Look for a stop on every trade and a rule for position size. Be wary of any robot that cannot explain this.
  • Is there a live, verifiable track record? A backtest is a simulation. See backtest versus live results.
  • Test on a demo account first. It costs nothing and finds setup problems before they cost money.
The right mental model

An EA is a tireless assistant that does exactly what it was told. The quality of the result is decided by the rules and the risk settings, not by the fact that it is automatic.

Frequently asked questions

Do I need programming skills to use an EA?

No. You install the file, attach it to a chart and set its inputs. Programming is only needed to write or change one.

Does an EA work when my computer is off?

No. The terminal has to be running and connected. Many people rent a VPS so the terminal runs all the time.

Are EAs allowed?

Most brokers allow them on MetaTrader 5, but check your broker's rules, especially about high-frequency styles.
