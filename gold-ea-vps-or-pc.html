Running an EA

Do you need a VPS to run a gold EA on MT5?

An Expert Advisor only trades while MetaTrader 5 is open, logged in and connected. So you need a computer that stays on while the gold market is open, which is 24 hours a day from Monday to Friday. That can be your own PC or a rented Windows VPS.

What the EA needs

  • MetaTrader 5 on Windows. Phones and MT4 cannot run MT5 Expert Advisors.
  • Algo trading switched on in MT5, and the EA attached to the right chart.
  • A stable internet connection. If the connection drops, the EA cannot manage open trades.
  • The computer must not sleep or restart. Turn off sleep and automatic restarts in Windows.

Setup checklist

  1. Install MT5 from your broker and log in to the account.
  2. Open the XAUUSD chart and attach the EA.
  3. Turn on Algo Trading and allow the EA to trade.
  4. Set Windows power options to never sleep, and pause automatic restarts where you can.
  5. Let alerts tell you if something stops. GoldTriEngine sends Telegram alerts for EA start and stop and for an offline heartbeat.

Questions people ask

Can I run a gold EA on my laptop?

Yes, if MetaTrader 5 stays open, the laptop does not sleep, and the connection is stable. For a live account that must run all week, many people prefer a VPS.

Does an EA work if my computer is off?

No. An MT5 Expert Advisor only runs while MetaTrader 5 is open and connected, so open trades are not managed while the computer is off.

Can I run MT5 EAs on a phone or MT4?

No. MT5 Expert Advisors need MetaTrader 5 on Windows. Phones cannot run Expert Advisors and MT4 uses a different format.

Does GoldTriEngine need a VPS?
